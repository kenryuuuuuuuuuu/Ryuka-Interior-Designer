# テレビと家具の設置高さ

2026-09-06。ゲストLDK対応表のBを実装しました。詳細な製品モデルへの対応付け（C）はまだ未実装です。

## 使い方

Three.jsの平面図で家具編集を有効にし、テレビなどの家具を選択します。「底面の床上高さ」をm単位で指定します。「高さ」は家具本体の寸法であり、別項目です。床置きは0です。リセットで元の配置へ戻せます。

変更はブラウザの下書きです。「furniture.jsonを書き出す」で正本へ取り込み、検証・Webデータ生成後に[再生成手順](REFRESH_WORKFLOW.md)を実行します。書き出しでは根拠メモも保持します。

## データ契約と範囲

- `data/furniture.json` の任意の `elevation` は、家具が属する階の床から家具底面までの距離mです。省略時は0、有限の非負数のみ許可します。GL座標ではありません。
- Blenderでは `levels.flN + elevation`、Unrealではその値をcmに換算します。Webのモデルとラベルにも加算します。
- `fur-045` はゲストLDK西壁側のテレビです。外形1.12×0.06×0.65m、底面床上1.00m、上端床上1.65m。位置・寸法は参考案として `estimated` とし、既存テレビボードは残しています。
- テレビの正面は正本座標のローカル+z。回転90度で東向きです。既存Web家具は負の回転角を使うため、テレビには正本通りの正の回転角を適用し、既存家具の向きは変更しません。他の家具の前面規約統一は別の検証単位です。
- Three.js内覧の家具当たり判定を、内覧開始時に下書き込みの配置から再生成します。底面が床上1.8m以上の家具は歩行障害物から除外します。身長1.8mを仮定した簡易判定で、天井への干渉や実際の頭部形状の検査ではありません。
- 壁面への吸着、金具・配線、画面映像、製品別モデル、Unrealでの家具編集や歩行判定は今回の対象に含みません。設置高さには天井による自動制限がないため、内覧で確認してください。

## 検証

- `node tests/test_furniture_web.mjs`：同梱Three.jsと実際のビューア関数で四方向の外形・正面、高さ編集、0への変更、無効値、リセット、書き出し、メモ保持、移動後と高所の歩行判定を検証。
- `python -m unittest discover -s tests -p 'test_*.py'`：省略時の互換性、負数・非数・真偽値などの拒否を含む。
- `tests/validate_interior_scene.py`：テレビの外形・設置高さと正本メモ、閉じた立体、GLBの往復を検証。
- ローカルの `build/guest-tv-v2` と `build/ue-tv-v2`：571メッシュの取り込み成功。従来569メッシュの外形差は0m。UEの外形照合の最大誤差は約0.000061cm。

成果物はローカルの `build/` に保持し、Gitへ追加しません。操作・検証に使うコードは既存の専用ブランチで管理しています。
