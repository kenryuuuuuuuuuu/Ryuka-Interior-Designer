# 日常利用の入口とフォルダ

2026-09-11：施主指示で、ゲストUE開発をmainへ統合し、日常利用の場所をプロジェクトのトップへ統一します。

## 開くファイル

- 家具の編集：トップの `interior-white-model.html` をブラウザで開きます。HTMLのソースコードを直接編集する必要はありません。
- UEの内覧・更新：トップの `interior-launcher.cmd` をダブルクリックします。
- 最初に「モデルを選ぶ」でゲスト・自宅・全館の範囲を確認します。旧 `guest-launcher.cmd` も同じランチャーを開く互換入口です。
- 残課題：[今後の作業](BACKLOG.md)。

家具をブラウザで変更→furniture.jsonを書出し→ランチャーで差分確認・正本へ反映→モデル更新→UEで確認、の順で使います。ダウンロードしたJSONは取込用であり、自動的に正本にはなりません。

旧HTMLのブラウザ内保存はブラウザが管理しています。旧画面だけに残る未書出しの配置がある場合は、そのタブからJSONを書き出してから新しい入口へ取り込んでください。ファイル移動でブラウザ内保存まで移行済みとは扱いません。

## 置き場所

| 場所 | 用途 |
|---|---|
| トップのHTML・cmd | 日常の起動入口 |
| data/ | 建物・家具等の正本。建物寸法はhouse.json、家具配置はfurniture.json |
| scripts/・blender/・unreal/ | 共通の生成・編集処理 |
| generated/ | 正本から生成するWeb表示データ。手編集しません |
| build/launcher/ | ローカル設定、比較記録、ログ、取込前バックアップ |
| build/scenarios/ | 名前付き保存案 |
| build/W08-F-delivery/ue/ | W08-Fの全館モデル。次の更新では新しい出力ができます |
| build/W08-G-update-v3/ue/ | 既存のゲストモデル。選択を戻して使用できます |
| build/archive/ | 過去の生成物・検証証跡・旧作業場所のローカル資料。日常編集には使いません |
| docs/tasks/ | Claudeへの仕様、実装報告、レビュー履歴 |

旧 `build/worktrees/visual-twin` は日常入口として使いません。今後開発用worktreeが必要な場合はプロジェクトの外に作り、日常版への統合時に案・設定への影響を確認します。過去の報告書にある旧パスは当時の証跡であり、現在の起動先ではありません。

## ローカルデータの扱い

build内のモデル・案・比較画像・ローカル設定はGitへ入りません。Gitのコミットだけではこれらのバックアップにはならないため、必要に応じてbuild/launcherとbuild/scenariosおよび使用中モデルも別途バックアップしてください。今回は過去の生成物を削除せずアーカイブします。過去証跡の入力ハッシュやパスは書き換えず、使用中モデルのrepo-root.jsonだけを新しい日常入口へ接続し直します。

## 全館の操作手順（W08-F）

1. `interior-launcher.cmd` をダブルクリックします。「モデルを選ぶ」で、範囲と有効表示を確認して選択します。全館の引渡しモデルは `build/W08-F-delivery/ue/` です。ゲスト版へ戻る場合も同じ一覧で選べます。
2. 「家具を編集する」でThree.jsを開き、家具編集を行い `furniture.json` を書き出します。ブラウザ内保存だけでは正本/UEへ反映されません。
3. 「家具JSON取込」で書出しファイルを選択し、全件差分とnote/statusの消失を確認して反映します。これは全館の家具正本への反映です。現在選択したモデルの範囲外の家具も含みます。
4. 内覧・エディタをF5/保存して閉じ、「モデル更新」→「更新開始」。選択したモデルと同じ範囲（guest/home/whole）を新しく生成します。成功時だけ新モデルへ切り替わります。失敗時は工程・理由・ログを確認し、前モデルを続けて使用できます。
5. 「内覧の開始位置」で「前回の続き」「自宅入口」「ゲスト入口」を選び、「内覧を開く」を押します。入口指定は今のセッションの視点のみ変更し、仕上げ・照明・扉の保存条件を保持します。F5を押すまで元の保存位置を置換しません。旧モデルでは更新するまで「前回の続き」のみ表示されます。
6. WASD・マウスで内覧、Eで近くの扉、1/2/3で現在室の仕上げ、4/5で手動太陽高度、F5で保存、F9で保存へ復帰。自宅は階段で2階へ移動できます。入口を変え直す場合は内覧を閉じ、ランチャーで選び直します。
7. 「案と比較記録」で保存状態に名前を付けます。対象範囲が一覧に表示されるので、ゲスト案と全館案を区別できます。既存案の読込・詳しい面/照明/昼夜比較は「編集・比較を開く」→UEの「ツール → 内装比較」を使います。
8. 内覧で対象室へ移動してF5保存後、「仕上げA/Bを記録」。最新のF5/エディタ保存を選び、対象室variantだけを変えて撮影します。共有用コピーは「共有用コピーを作る」で別フォルダへ作成します。自動送信・公開はしません。

更新・撮影・家具反映と内覧/エディタは同時実行できません。処理の完了または内覧/エディタの終了後に次の操作へ進みます。ランチャー外で開いたUEも保存して閉じてから更新してください。

設定と選択モデルは `build/launcher/config.json`、名前付き案は `build/scenarios/`、比較記録は `build/launcher/comparisons/` に残ります。PC再起動後も同じ入口を使用します。過去モデルへ戻るには「モデルを選ぶ」で前の有効モデルを選択します。ブラウザの未書出し内容はそのブラウザが管理しています。
