# ファミリークロークの使い方・配置

2026-09-16。対象は `room-1f-12`（自宅1階北東、壁芯約3.64×1.82m）。施主承認の夫婦＋子供最大2人向け検討案です。

## 配置

| ID | 配置 | 幅×奥行×高さ（m） | 設定 |
|---|---|---|---|
| fur-cloak-01 | 北・西：夫婦の長物 | 1.00×0.60×2.20 | パイプ1.80m |
| fur-cloak-02 | 北・中央：夫婦の日常着 | 1.00×0.60×2.20 | パイプ1.00／1.95m |
| fur-cloak-03 | 北・東：子供2人 | 1.00×0.60×2.20 | パイプ0.85／1.65m。成長に応じ変更可能 |
| fur-cloak-04 | 東：ボックス可動棚 | 1.10×0.45×2.20 | 35×40×25cm相当の蓋付き箱を2列×4段 |
| fur-cloak-05 | 南：浅型引き出し | 0.60×0.30×0.85 | 下着・靴下・小物 |
| fur-cloak-07 | 西壁：薄型姿見 | 0.38×0.03×1.60 | 底面は床上0.20m |

主通路は800mm。東棚前は南の引き出し右端から685mm空けています。南側にもう1台の高い棚を置く初期案は、東側の箱を引き出す空間を塞ぐため採用しませんでした。南収納は引き戸の開口と全開時の移動先を避けています。姿見は通路の西壁に沿わせています。

木部は明るいオーク色、本体は温かい白、金物は艶を抑えた金属色です。収納本体の色は家具固有の仮仕上げとして固定し、室の壁・床のA/B切替とは分けています。既存ダウンライト2灯を利用します。

## 編集

1. HTMLを再読み込みし、平面図の「家具編集」で対象の家具を選択します。
2. 幅・奥行・高さ・位置・回転は既存の家具操作を使います。
3. ハンガー収納は「パイプ高さ」、可動棚は「棚板高さ」をmで入力します。複数は `0.85, 1.65` のように低い順にカンマで区切り、入力欄の外をクリックすると反映します。
4. 「収納物の見本を表示」で衣類・箱の表示を切り替えます。見本は収納ユニットに追従し、移動や削除で取り残されません。
5. 家具JSONを書き出し、ランチャーの家具取込み→モデル更新でUEへ反映します。収納設定も差分表示・検証・保存対象です。

家具追加のカテゴリは、造作側にハンガー収納・可動棚・姿見、家具側に浅型引き出し・単体の蓋付きボックスがあります。新しく追加した家具にも自動でUE用形状が割り当たります。

高さの制限はパイプ同士650mm以上、棚板同士280mm以上です。収納物は簡略形状の見本で、棚を小さくした場合は見本の箱も内寸に合わせて縮小します。特定製品の適合判断には、単体ボックスを実寸で追加するか、実製品の寸法を別途照合してください。衣類見本は実際の家族の所有数を示しません。引き出しは外観モデルで、開閉アニメーションはありません。

## データと生成

- 正本：`data/furniture-catalog.json`、`data/furniture.json`。家具は6種類を追加、配置は6台です。
- インスタンスの `storage`：`railHeights`／`shelfHeights`（底面からの高さm）、`contents`（見本表示）。省略時は寸法に応じた既定値。
- Three.js：`storageSettings`／`storageParts`／`drawStorage`。既存の追加・削除・編集・書出しを使用。
- Blender／UE：`blender/storage_assets.py`。種類で自動選択するため、個々の家具IDを `asset-bindings.json` に追記する必要はありません。
- 管の円形断面、木・金属・布・鏡を別部品として生成し、配置・回転・高さは家具正本から取得します。
- 検査：`tests/test_storage_assets.py`、`tests/test_furniture_web.mjs`。配置・壁内法・通路・箱数・編集往復・異常値拒否・JS/Pythonの部品寸法一致を確認します。
