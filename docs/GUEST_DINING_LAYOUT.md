## 空き寸法の読み方

以下は共通データの平面外形から計算した概算です。人の動き、椅子を引く動作、家電扉の開閉を検証済みという意味ではありません。円卓は外接矩形で保守的に計算しています。

| 区間 | 概算 | 扱い |
|---|---|---|
| 円卓東端〜キッチン西端 | 0.645m | 狭めの作業・通行域。扉の開閉を含めて次回レビュー |
| ローテーブル東端〜円卓西端 | 0.925m | リビング側とダイニング側の間の空き。西側に3脚目の食卓椅子を追加すると狭まる |
| ソファ前端〜ローテーブル北端 | 0.280m | 手が届く家具間隔としての仮案。主通路としては扱わない |
| ローテーブル南端〜カウンター椅子の背側外形 | 0.230m | 通り抜け用の幅は不足。カウンターへの出入りは側方から検討 |

このため、画像①で見える食卓の3脚をそのまま採用せず、まず食卓2席＋窓際2席で配置しています。4人が同じ円卓を囲むことを満たした案ではありません。食卓席数の確定時には円卓の位置・径、窓際席との配分を再検討します。

## モデルと更新

`round-table-v1` は天板と4本の脚の5部品、`chair-timber-v1` は座面・脚・背の支持材・曲線の笠木の9部品です。すべて自作の仮形状で、実製品や編み座の質感は未再現です。

- 円卓の対応寸法：幅・奥行0.70〜1.40m、高さ0.65〜0.80m。幅と奥行を別々に変更すると楕円になります。
- 木製チェアの対応寸法：幅0.40〜0.65m、奥行0.42〜0.65m、高さ0.75〜1.00m。
- Three.jsでは軽い簡易形状を表示します。Blenderでは曲線の背を生成し、Unrealへ渡します。正本寸法・配置・回転・設置高さは共通です。
- 対応表からの詳細モデル割当を使います。新型の円卓・木製チェアは、明示割当がなくても型に対応する既定モデルを生成し、矩形の箱などに黙って置換しません。
- Three.js内覧の当たり判定は従来と同じ外接矩形の区間です。円卓の角付近では見た目より保守的です。曲線に沿う衝突判定への変更は未実装です。

## 検証と次の作業

Webの実際の家具描画関数と、Blenderの実際の生成処理でサイズ変更・四方向回転・設置高さを検証しました。Blenderの円卓・椅子は合計16ケースで閉じた立体と正本外形を確認しています。通常の生成工程でも全メッシュとGLB往復を検証します。

実行方法：`node tests/test_furniture_web.mjs`、`python -m unittest discover -s tests -p 'test_*.py'`。Blenderで `tests/check_dining_assets_blender.py` を実行すると実モデルの16ケースを検証できます。

次はキッチン・冷蔵庫の前面方向を両ビューアで照合し、レンジフード・水栓・エアコン本体を加えます。家具をそろえた後、床の石・タイル調仕上げ、天井の木板、布の質感、露出・光を調整します。今回の確認画像も仮の採光条件であり、実敷地での明るさを示すものではありません。
