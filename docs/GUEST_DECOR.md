# ゲストLDKの装飾

`data/visual/guest-decor.json` が装飾の設定元です。建物・家具の正本を参照してBlenderで生成し、GLB経由でUnrealへ取り込みます。Three.jsの家具編集UIには今回の装飾は表示されません。家具や窓を編集した場合は、JSONを書き出して正本へ反映し、通常の更新ワークフローを実行してください。

| 装飾 | 参照先 | 今回の仮設定 |
|---|---|---|
| ラグ | コーヒーテーブル `fur-038` | 1.6 × 1.2m、厚さ10mm。中心・回転に追従。寸法は独立設定 |
| ロールスクリーン2枚 | `op-006` / `op-007` | 開口幅＋60mm、上端は窓に追従、窓高さの22%を下げる |
| 楕円木製格子・棚 | ソファ `fur-011` と部屋境界 | 幅950・高さ1100mm、下端は床＋1150mm。ソファのx位置に追従し、北側の水平壁に固定 |

格子は家具の回転には追従しません。北側に取付幅を確保できる壁がなければビルドを止めます。スクリーンは現在、南面の外窓のみ対応します。参照先が削除された場合もビルドを止めるため、不要な装飾は設定のitemsから明示的に取り除いてください。寸法・設置案はすべてestimatedです。構造梁は追加していません。

現段階は形状と配置のたたき台です。ラグやスクリーンは既存のfabric材質を共有し、織り目の実製品テクスチャや透過性能は再現していません。スクリーンは不透明で遮光に影響しますが、実際の採光を評価できる透過率・敷地方位の校正は未実施です。小物・植物・クッション・布のたるみは今後追加します。
