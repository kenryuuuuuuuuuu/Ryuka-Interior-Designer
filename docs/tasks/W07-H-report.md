## 実装

- home＝自宅25区画、whole＝ゲストを含む33区画を追加。既存guest/guest-pilotのIDと範囲は維持します。

- 各階を区別して壁材質を割り当て、斜め玄関の床/天井を実ポリゴンで分割。自宅LDKの勾配・平坦混在天井は正本envelopeを使用します。
- 全館家具45点・照明40灯。自宅の幅広洗面、洗濯機、浴槽、タンクレストイレ等へ簡易部品を適用。2階のベッド3台は木枠/マットレス、机2台は天板/脚を追加し、外形箱表示を解消。部品・材質はestimated、位置/向き/外形寸法は既存正本を継承します。
- 31建具接続を同じ階の室境界から解決。斜め框・アーチ開口、折れ戸/両折れ戸、回転と移動を組み合わせる葉の開閉を追加しました。
- 正本の13段・直進→180度回り→直進・床開口・ガード壁から階段を生成。歩行用の非表示斜面を踏鼻に沿って生成し、実際のCharacterMovementで上り下りします。表示形状と歩行衝突は分離し、階段下の収納空間を保持します。
- 室/階判定に高さを使用し、段上のF5/F9で高さを保存・復元。任意保存の検証は維持し、階段と床の継ぎ目で実歩行を誤拒否する安全判定を修正しました。
