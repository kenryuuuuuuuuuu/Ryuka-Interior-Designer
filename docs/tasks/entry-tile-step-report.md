# 玄関・土間の床仕上げと段差（2026-09-13）

施主指定の4区画（自宅玄関 `room-1f-08`、土間 `room-1f-09`、南土間 `room-1f-18`、玄関(民泊) `room-1f-02`）を、通常床より100mm低いタイル床にしました。高さは `data/house.json` の各室 `floorOffsetM` が正本です。タイル仕上げは `data/visual/unreal-finishes.json` の `roomFloorFinishes` が正本です。どちらも現時点では推定仕様です。

Three.jsの床面を室の多角形で切り分け、低いタイル面と段差側面を描画します。Blender/UEも同じ室IDと高さを使い、UEの仕上げA/Bを切り替えても4室のタイル指定を保ちます。UEの歩行設定は室間の床高差を越えられるよう調整しました。家具の床基準も室の床高に追従します。

検証：240件のunittest、Web床面の面積・高さ検査、house/furniture validator、生成Webデータ一致検査に成功。全館refreshは `build/entry-tile-step-final/` に完了し、UE取込・状態転送に成功。Blenderモデルで4室の床上面が0.607m、通常ホールが0.707mであることを確認しました。UEのDX12実描画による全館自宅スモークはPASS（階段往復と保存復元を含む）。

床下げ100mm、30cm角、2mm目地、色・粗さは見え方確認用の仮値です。実際の段差寸法、框の納まり、採用タイル、防水・滑り仕様は施主・施工会社確認待ちです。施主の画質・歩き心地の評価は未実施です。
