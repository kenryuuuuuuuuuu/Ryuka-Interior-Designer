# 内覧の照明・季節時刻操作（2026-09-13）

全館ウォークスルーに `L`（現在室の照明一括ON/OFF）、`T`（9/12/15/18/21/24時）、`Y`（春夏秋冬）を追加しました。照明は器具ごとの既存 `roomStates[*].fixtures` を操作します。将来の個別器具選択で同じ状態と `ApplyConditions()` を使えます。変更はF5で保存し、F9で復元できます。

時刻は既存の `solar_position.position()` で、`data/visual/walkthrough-time-presets.json` の代表日と敷地から生成します。モデルに `site.local.json` があればその入力を使い、なければ北緯35度・東経135度・図面上を北とする**架空の仮敷地**を使います。仮敷地は実建物の採光予測ではありません。夜は太陽・空を非表示にし、照明の器具別ON/OFFは保持します。画面に仮敷地・未校正を常時表示します。生成関数は任意の日付と時刻リストを引数に取れますが、任意日付を入力する画面は今後の作業です。

検証：Python unittest 241件。全館refresh、実UE DX12の全館自宅スモークで階段往復、Lで3灯ON、Tで9時、Yで夏、21時の夜間化、F5/F9で照明・日時の復元を確認。最終モデルの出力と切替先は `build/walkthrough-controls-v2/ue` です。

未確定：実敷地位置・図面真北、採用品の配光・照度、夜の周辺光、任意日付UI、個別照明UI。施主の見え方・操作感の確認待ちです。
