## 正面方向と互換性

ゲスト用の型では `rotationConvention: source` を使用し、Three.js・Blenderの両方でローカル+zを正面にします。270度で西向きになります。既存の自宅用キッチン・冷蔵庫の型と向きは維持しました。

キッチンの前面が壁側に向いていたBlender表示を修正しました。シンクの左右位置も回転に従って変わるため、水栓は修正後のシンク、フードは修正後のIH位置に合わせています。シンクが塞がっていないこととIHが天板に隠れていないことは、従来のレイ検証を続けています。

## 生成と編集の範囲

Webで新しい家具を選択し、寸法・位置・回転・底面の床上高さを編集できます。書き出して正本に反映するとBlenderとUnrealへ再生成できます。

フードは笠・フィルター・煙突の3部品、水栓は台座・胴・吐水部・レバーの4部品、エアコンは本体・前面・吹出口の3部品です。単純な仮モデルで、送風・給排水・換気性能をシミュレーションするものではありません。エアコン電源などの既存電気設備データは変更していません。

**フードと水栓は独立した配置です。** キッチンへの親子追従は未実装で、キッチンの移動・回転・寸法変更時は共通データ上でフードと水栓も再調整してください。親IDと相対配置を導入する場合は、Webのドラッグ・書き出し・当たり判定も含む次の独立した実装単位にします。

## 検証

- `node tests/test_furniture_web.mjs`：新しい3種類の四方向の外形・設置高さ、キッチンと冷蔵庫の室内向きを確認。
- Blenderで `tests/check_fixture_assets_blender.py`：3種類×2寸法×4方向の24ケースで、閉じた立体と正本外形・メモの保持を確認。
- `python -m unittest discover -s tests -p 'test_*.py'`：対応寸法範囲外を拒否する検証を含む。
- 通常のBlenderパッケージ生成でシンク・IH、閉じた立体、GLB往復を検証し、Unrealで全メッシュの外形を照合。
