# 石調床・木板天井の参考案

2026-09-07。既存の `natural`・`warm` に加え、`reference`（石調の床・木板天井）を追加しました。建物・家具の形状や配置は変更していません。

## 操作と設定

新しく生成したUnrealプロジェクトの「ツール → 内装比較 → 石調の床・木板天井」で切り替えます。従来の2案にも戻せます。「比較条件とレベルを保存」後は、通常の[一括更新](REFRESH_WORKFLOW.md)で案名・視点・光を引き継げます。

色は `data/visual/guest-ldk-study.json` の `variants.reference`、板・タイル寸法は `data/visual/unreal-finishes.json` の `variantOverrides.reference` にあります。いずれも製品未選定の推定設定です。

| 面 | 仮仕様 |
|---|---|
| 床 | 淡い石調色、600×600mmのタイル割り、目地2mm、粗さ0.72 |
| 天井 | 暖色の木板、幅100mm・長さ3600mm、目地1.2mm、粗さ0.65。長手は図面東西方向 |

今回の案は生成プロジェクトの床・天井へ役割単位で一括適用します。部屋ごとの仕上げ指定は未実装です。参考画像にある梁の新設、窓位置の変更、実際の床厚・天井下地の変更は行っていません。

## 模様の寸法とエンジン間の扱い

床・天井に、1UV単位が面上の1mとなる座標を生成します。現行の南北方向の勾配に対して、天井面に沿う長さへ補正します。Blender側の `surface_finishes.py` と、UE側の `surface_finish.hlsl` は同じ板幅・長さ・目地寸法を参照します。将来、東西にも傾斜する天井を追加する場合は座標生成と検証の拡張が必要です。

BlenderはBrickノードによる板・タイル割りと浅い凹凸、UEは面上座標から計算する目地・色変化・仮木目を使用します。エンジンごとの描画処理と露出が異なるため、画素単位の一致や実材の再現を保証するものではありません。実製品の写真テクスチャ、石の細かな表面、木の節、施工上の割付は今後の調整対象です。

既存2案の仕上げ設定はそのままです。古い2案のみの生成パッケージでは、新しいメニュー項目を表示しません。3案を利用するには現在のソースからBlenderパッケージごと再生成してください。

## CLI

Blender生成は `scripts/build-visual-twin.py --variant reference`、UE撮影は `scripts/capture-unreal-study.py --variant reference` に対応します。その他の必須引数は従来どおりです。

日時別比較を3案で行う場合は `scripts/compare-unreal-studies.py --variants natural warm reference` を指定します。比較CLIと一括更新のギャラリー既定値は、従来の2案を維持しています。

## 検証・成果物

- 既存2案の設定が変わらないこと、板幅・目地等の無効値を拒否することをユニットテストで確認。
- Blenderの `tests/check_surface_uv_blender.py -- パッケージディレクトリ` で床・天井25メッシュの面上距離とUV距離を比較。GLBへの往復後も確認。
- 全612メッシュの外形は仕上げ追加前と一致。UE取り込みでも全外形を照合。
- ローカル `build/guest-reference-v1` がBlender成果物、`build/ue-reference-v2` が同視点比較用、`build/ue-reference-v3` が床・天井を広角で確認するUE成果物です。比較ページはローカル `build/reference-review/index.html` にあります。`ue-reference-v1` は補助Pythonモジュールの配置不足で取り込みに失敗した診断用出力で、使用しません。生成スクリプトは修正済みです。
