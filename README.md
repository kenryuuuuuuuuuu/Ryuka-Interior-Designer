# Ryuka Interior Designer

自宅新築プロジェクトの内装3D白模型（Three.js）。

寸法・間取り・ドア・窓の位置を、施工会社の実施図面と参考資料（マイホームクラウド間取り図）の突き合わせ検証を通じて構築している。

## 現状のステータス（2026-08-13時点）

- 1F：民泊棟・自宅（ヌック〜LDK）・A4水回りまで、全区画が確度「高」
- 2F：全区画が確度「高」
- 室内ドア：19箇所配置済み
- 窓・外部ドア：施工会社図面ベースの確定データ＋今回のセッションで調整した箇所あり
- 天井高：全室2,400mm（**推測値、施工会社への確認が必要**）
- 家具配置：未着手（次のステップ）

## ファイル構成

- `interior-white-model.html` — メインの3Dビューア（単体で開けば動作する）

## 使い方

`interior-white-model.html` をブラウザで直接開く。ビルド不要、外部依存はCDN経由のThree.js（r128）のみ。

- 左上「☰」：メニューの表示/非表示
- 右上「▦ 平面図モード」：真上からの正射投影ビュー（寸法比較用）
- メニュー内チェックボックス：レイヤーごとの表示切替（外皮・室内間仕切り・窓ドア・防音壁・屋根・室内ドア位置・寸法値・部屋ラベル・910mmグリッド）

## データの確度について

各部屋・開口部には `conf`（確度）が付与されている。

| 表記 | 意味 |
|---|---|
| ● 高 | 実施図面または複数資料の相互検算で確定 |
| ◐ 中 | 1辺確定＋面積からの逆算など、部分的な根拠あり |
| ○ 低 | 目視のみ、または未検証 |

「低」が残っている箇所は、より詳細な参考資料が入手でき次第、精緻化する。

## 既知の制約

- 天井高は施工会社の断面図が存在しないため推測値
- 一部の低確度区画は内部の細分（例：トイレ・洗面・収納の配置）が未解決
- CAD原本（DXF等）があれば、この白模型全体の精度を大きく上げられる
